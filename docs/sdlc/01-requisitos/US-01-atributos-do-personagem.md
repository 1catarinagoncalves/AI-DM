# US-01 — Atributos do personagem

**Épico:** Free
**Status:** Feito
**Depende de:** nenhuma
**Criada em:** 28-06-2026

---

## História

> **Como** jogador,
> **quero** ver os atributos do meu personagem na interface web,
> **para que** possa acompanhar os atributos.

---

## Contexto e motivação

### O problema observado

Embora ao criar o personagem, o jogador atribua pontos de atributo para ele, aa interface web ao jogar com o mestre, esses dados não aparecem.

### Por que a solução atual não basta

Os dados existem no banco de dados, apenas não estão sendo ostrados para o jogador depois que ele cria o personagem.

### A proposta

Abaixo de onde fica o HP do personagem, adicionar os dados de atributos do mesmo, colocando o nome e os valores dos atributos. Essa regra deve valer tanto para o sistema free quanto d&d.

---

## Escopo

### Dentro do escopo

- Nome e valores de atributos do personagem da página de chat com o mestre.

### Fora do escopo

- Calcular os modificadores dos atributos.
- Modificar valores dos atributos devido a acontecimentos da história.
